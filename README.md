# 🔍 The Case of the Fifth Word — NCERT Study Portal

A modern, responsive, educational web application containing complete textbook solutions and interactive study resources for **Unit 3: Mystery and Magic — "The Case of the Fifth Word"** by Donald J. Sobol (NCERT Class 8 English *Poorvi*, Pages 107–110).

---

## 🌟 Key Features

1. **Complete Page-by-Page Textbook Solutions (Pages 107 to 110):**
   - **Page 107:** Mystery resolution breakdown & Fact vs. Opinion statements (Q1–Q6).
   - **Page 108:** Fact vs. Opinion statements (Q7–Q8), Character Traits Table (knowledgeable, humble, keen listener, cleverness), and Extract 1 introduction.
   - **Page 109:** Extract 1 Questions ((i) to (iv)), Extract 2 introduction, and Extract 2 Q(i).
   - **Page 110:** Extract 2 Questions ((ii) to (iv)), 6 Concise Analytical Answers, and an ultra-concise Character Sketch of Leroy Brown (Q7).

2. **Interactive Detective Lab (Code Decoder):**
   - Visual breakdown of Nolan's calendar cipher:
     - `NOM` &rarr; `MON(DAY)` (Monday)
     - `UTES` &rarr; `TUES(DAY)` (Tuesday)
     - `SWEDEN` &rarr; `WEDNES(DAY)` (Wednesday)
     - `HURTS` &rarr; `THURS(DAY)` (Thursday)
     - **5th Word:** `FRI(DAY)` &rarr; `FIR` tree!

3. **Interactive Study Modes:**
   - **🎯 Practice Mode:** Hides all answers with a single click so students can self-test and reveal answers individually.
   - **📋 One-Click Copy:** Easily copy any question and model answer for homework or revision notes.
   - **🔎 Real-time Search:** Instant keyword search across questions, answers, and extracts.
   - **🌙 Dark & Light Themes:** Toggle between clean academic paper and detective midnight theme.
   - **🔊 Text-to-Speech:** Built-in web speech narration for accessibility.
   - **🖨️ Print / PDF Ready:** Clean print stylesheet for generating clean study sheets.
